## How AI Was Used

ChatGPT was mainly used as a development assistant to:

* Discuss and review architecture and design decisions.
* Help with ASP.NET Core Identity and JWT authentication.
* Review implementation approaches and resolve development issues.
* Help structure the project documentation.

I did not rely on AI to blindly generate the entire project. I discussed the implementation with AI, reviewed the suggestions, made the final technical decisions, and implemented and adjusted the code based on the project's requirements.

AI was used as a supporting tool, while the final implementation and decisions were reviewed by me.
